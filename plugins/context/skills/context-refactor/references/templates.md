# テンプレート

見出しは必要なものだけ使い、空の節は作らない。表は使わず箇条書きにする。

## ルート AGENTS.md

```markdown
# <プロジェクト名>

<目的を 2〜3 文>

## コマンド

- `<install コマンド>`
- `<test コマンド>`: <補足が要るときだけ>
- `<lint / typecheck コマンド>`

## 規約

- <このリポジトリ固有の規約>。<理由 1 文>

## 落とし穴

- <コードからは読み取れない注意点>

## 参照先

- <作業の種類>: <読むファイルや skill>
```

## サブディレクトリ AGENTS.md

ルートに CLAUDE.md（`@AGENTS.md` の import や symlink を含む）がある場合は、同じディレクトリに `@AGENTS.md` だけの CLAUDE.md（または AGENTS.md への symlink）も置く。置かないと既定の設定ではこの AGENTS.md が読まれない。

```markdown
# <パッケージ名>

<責務を 1〜2 文>

## コマンド

- `<このパッケージ固有のコマンド>`

## 環境変数

- `<NAME>`: <用途>（必須 / 任意）

## 注意点

- <このパッケージ固有の注意点>
```

## CLAUDE.md（Claude Code 固有の追記がある場合だけ）

```markdown
@AGENTS.md

- <Claude Code にだけ効かせる指示>
```

## README.md

```markdown
# <プロジェクト名>

<1 行説明>

## 概要

<目的と主な機能を 2〜3 文>

## インストール

<必要なコマンドだけ>

## 使い方

- `<よく使うコマンド>`: <説明>

## ライセンス

<ライセンス>
```
