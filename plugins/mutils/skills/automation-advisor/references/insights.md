# /insights データソースガイド

`/insights` は Claude Code のビルトインコマンドで、セッション履歴から分析済みの知見（作業の分布、うまくいっているワークフロー、繰り返される摩擦、CLAUDE.md への追記提案など）を返す。ccsight が生データを返すのに対し、こちらは解釈済みの記述になる。

## アクセス方法

skill からは実行できない。ユーザーが最近実行していれば出力を共有してもらう。無ければこのデータソースは省き、ccsight やセッションファイルで補う。出力の構成は Claude Code のバージョンで変わりうるので、特定のフィールド名を前提にせず、共有された内容を読んで判断する。

## automation-advisor での使い方

- 繰り返される摩擦・問題の記述 → 「未言語化型」の候補。hook / rule / skill で自動化できる繰り返しを拾う
- CLAUDE.md / AGENTS.md への追記提案 → ルール候補として、既存のルールと重複しないか確かめてから採る
- うまくいっているワークフローの記述 → 視点 A（既存の自動化）に含める
- 古い出力はセッション構成が変わっている可能性があるので、実行日を確かめる
