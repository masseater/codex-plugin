# Vault 検索

Vault が存在しなければ、その旨を報告して終える。ノート形式は `../../assets/note-format.md` を参照する。

## 条件が明確な検索

ユーザーが条件を指定したときは、その条件だけで検索して結果を返す。

- キーワード: 本文を全文検索する
- タグ・種別: frontmatter の `tags` / `type` で絞る
- 被リンク: `[[ノート名]]` を含むノートを探す

```bash
find ~/Documents/Zettelkasten -name '*.md' -not -path '*/.trash/*' -exec grep -li -E '<pattern>' {} +
```

grep はヒットなしで exit 1 を返すが、エラーではない。

## 曖昧な想起検索

1. クエリから主要な名詞・概念を取り出し、同義語・言い換え・英日の対訳を 3〜5 個加える。それ以上広げるとノイズが増えるため
2. 全キーワードを 1 回の grep にまとめて検索し、ヒットを「frontmatter（title / tags）で一致」と「本文だけで一致」に分ける。タグやタイトルは意図して付けた関係なので、前者を上位にする
3. 上位 5 件の wikilink 先と被リンク元を候補に加え、どのノートから辿ったかを記録する
4. 候補が 10 件を超えたら、各候補の frontmatter と冒頭 5 行を読み、クエリとの関連度で上位 10 件に絞る

## 結果の提示

- 各ノートのタイトル・種別・タグ・パス
- 冒頭の要約（2〜3 行）
- ヒットした理由（タグ一致 / 本文一致 / wikilink 経由）。wikilink 経由ならどのノートから辿ったか
- 該当がなければ「Vault に該当するノートは見つからなかった」と 1 行で伝える
