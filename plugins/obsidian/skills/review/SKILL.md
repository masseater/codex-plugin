# Zettelkasten 振り返り

Vault（`~/Documents/Zettelkasten`）が存在しなければ、その旨を報告して終える。

## モード

ユーザーの言葉からモードを選ぶ。指定がなければランダムにする。

- ランダム（「何か見せて」）: ノートを 3 件ランダムに選ぶ
- 期間（「今週の」「先月の」）: 期間内に作成されたノートを `created` と `git log` から集めてダイジェストする
- テーマ（タグや話題の指定）: タグと本文で関連ノートを集め、種別ごとにまとめる
- 接続（「つながり」「関連」）: 直接リンクされていないが内容が関連するノートの組を提案する
- 忘却（「忘れてる」「久しぶりに」）: `git log` の最終更新が 30 日以上前のノートを古い順に 5 件出す

## 提示

各ノートについて要約と、今の作業や他のノートとの関わりを 1〜2 文添える。新しい接続を見つけたら wikilink の追加を提案し、ユーザーが承認したら追加して Vault で commit する。
