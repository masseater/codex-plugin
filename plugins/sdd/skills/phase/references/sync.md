# sync: 実装の進み具合を phase ファイルへ反映する

作業を中断する前や、別の手段で実装を進めた後に、phase ファイルを実際の状態に合わせる。

1. 対象の spec と Phase を決める。引数がなければ、この会話で扱っていた spec と Phase を使い、分からなければ `AskUserQuestion` で選んでもらう
2. phase ファイルの各タスクについて、実装とテストが揃っているかを確かめる。手がかりは、タスクの「出力」に書かれたファイルの有無と中身、`git log` と `git diff`、テストの実行結果
3. 揃っているタスクのチェックボックスを `- [x]` にし、揃っていないものは `- [ ]` に戻す。途中のタスクは、タスク詳細に「残り: <残っている作業>」を 1 行足す
4. Phase の `status:` を合わせる（1 つでも着手していれば `in_progress`）。変えたら sdd-webapp に反映する
5. 反映した内容と、再開時の最初のタスクを伝える
