# clarify: 「不明」をユーザーに確認する

1. `specs/<spec>/` 配下の全 Markdown（phases/ を含む）から `**不明**` を探し、ファイル・節・何が不明か・並んでいる案（案 A / B / C）を集める。見つからなければその旨を伝えて終える
2. 見つけた不明点を本文に一覧で書き出してから、`AskUserQuestion` で質問する。不明点 1 つにつき 1 問とし、1 回に最大 4 問まで同時に聞く。並んでいる案をそのまま選択肢にし、description に回答で書き換えるファイルと節を書く
3. 回答を反映する。`**不明**` の行と案の一覧を消し、決まった内容だけを書く。同じ決定が複数のファイルに関わるなら、すべて書き換える

   ```markdown
   <!-- 反映前 -->

   **不明**: 認証方式

   - 案 A: JWT
   - 案 B: セッション

   <!-- 反映後 -->

   認証方式は JWT を使う。
   ```
