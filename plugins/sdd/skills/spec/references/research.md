# research: 調査項目を調べる

overview.md の「調査項目」にある未完了の項目（`- [ ]`）を AI が調べ、結論を出す。調査項目名を指定されたらその項目だけ、なければ未完了の項目を順にすべて調べる。

## 1 項目の進め方

1. 何を決めるための調査かを overview.md の理由から確認する
2. 調査方法を選んで実行する: コードベースの既存パターン、公式ドキュメントや Web 検索、小さな PoC、ベンチマーク。推測ではなく、確かめた結果で判断する
3. 結果を `specs/research/<調査項目名>.md` に保存する。調査の計画や途中経過は書かず、結論と根拠だけを書く

   ```markdown
   # <調査項目名>

   ## 結論

   - 選択: <選んだ技術・手法>
   - 理由: <1〜3 行>

   ## 根拠

   <計測結果・比較・リスクなど、結論を支えるものだけ>

   ## 関連 spec

   - specs/<spec>/
   ```

4. overview.md の該当行を完了にし、結論とリンクを足す

   ```markdown
   - [x] <調査項目名> — 結論: [<選んだもの>](../research/<調査項目名>.md)
   ```

ユーザーの意思決定が要る問い（業務ルール、範囲の線引き）は調査で決めず、該当する文書に `**不明**` として残して clarify に回す。
