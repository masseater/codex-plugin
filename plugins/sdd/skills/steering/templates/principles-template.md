- 必須にする範囲: <TDD で進めるレイヤーやモジュール。例: ドメインロジックと API ハンドラ>

## コードの約束事

- 型: <例: `any` を使わない、`interface` より `type`>
- import / export: <例: barrel ファイルの扱い、循環参照の禁止>
- エラーハンドリング: <例: どこで捕捉し、どう伝播するか>
- セキュリティ: <このプロジェクトで特に注意する入力経路や認可の仕組み>

## Phase 管理

- Phase で不要になったコード・コメント・デバッグ出力は、その Phase の中で消す。次の Phase に持ち越すと、どの Phase の成果物か分からなくなるため
- 後続の Phase で使う予定の export / import を先に作らない。使う Phase で追加する。Phase 間の依存を減らし、各 Phase を自己完結させるため
